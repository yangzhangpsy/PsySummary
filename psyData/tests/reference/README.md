# rtdists alignment reference

PsySummary's cognitive-model implementation is an independent Python implementation. It does not
invoke R at runtime. Numerical behavior is benchmarked against `rtdists` 0.12-0.

## Covered subset

- Ratcliff diffusion: `a`, `v`, `t0`, `z`, `d`, `sz`, `sv`, `st0`, and fixed scale `s`.
- LBA: positive-truncated normal drift with `A`, `b`, `t0`, `st0`, `mean_v`, and `sd_v`.
- Racing diffusion: `A`, `b`, `t0`, `st0`, fixed scale `s`, and one `v` per accumulator.

The Python LBA does not currently expose the Gamma, Frechet, Lognormal, or Wald drift variants
available through the general `rtdists::dLBA` API. Trial-wise or accumulator-specific `A`, `b`, and
`t0` vectors are also outside PsySummary's current fitting interface.

## Numerical comparison

`generate_rtdists_cognitive_reference.R` regenerates the PDF, defective CDF, and conditional
quantile values used by `test_psydata_cognitive_models.py`. The grid includes both response sides,
multiple RTs, DDM across-trial variability, LBA positive drift, and RDM races.

`validate_rtdists_fits.py` performs the end-to-end fitting comparison. It asks `rtdists` to
simulate one dataset for each model, fits those datasets in R with the `rtdists` likelihoods and
`nlminb`, then fits the same CSV files through PsySummary's production `fit_cognitive_model()`
entry point. Run it from the repository root with:

```bash
python psyData/tests/reference/validate_rtdists_fits.py
```

Use `--r-library PATH` when `rtdists` is installed in a non-default R library. By default, data and
reports are written under `reference/rtdists_fit_validation/`. `fit_comparison.csv` is the complete
machine-readable comparison and `fit_comparison.md` is the readable report. The command exits with
status 1 when either fit does not converge or a configured NLL/parameter tolerance is exceeded.

- LBA and RDM PDF differences are normally below `1e-9`; CDF and quantile differences are normally
  below `1e-6` on the reference grid.
- DDM PDF values without variability match near machine precision. With `sz`, `sv`, and `st0`
  enabled together, nine-point Gaussian quadrature keeps the tested near-onset absolute error below
  `2e-6`.
- DDM CDF and conditional quantile checks allow for the selected `rtdists` precision setting;
  quantiles are checked within `0.4 ms` on the reference case.
- A fixed-parameter DDM likelihood is checked directly against the `rtdists` sum of log densities.

Random generators use different R and NumPy random streams, so sample-by-sample equality is neither
expected nor tested. PDF/CDF/quantile agreement is the deterministic distribution-level check.

## Fitting comparison

The initial Python implementation used L-BFGS-B with a discontinuous penalty for coupled constraints
such as `b > A`. Both SciPy and R L-BFGS-B could stop at the initial values while reporting
convergence. PsySummary now uses SLSQP with explicit nonlinear constraints and feasible additional
starts.

Using data generated by `rtdists`, identical starting values, bounds, and free parameters produced:

| Model | rtdists likelihood + R `nlminb` | Python likelihood + SLSQP |
| --- | --- | --- |
| DDM | NLL `136.3219587598` | NLL `136.3219587356` |
| LBA | NLL `90.7030139361` | NLL `90.7030139364` |
| RDM | NLL `98.5376417990` | NLL `98.5376417993` |

The fitted parameters differed by less than `5e-6` in these comparison runs. Optimizer equality is
not expected because `nlminb` and SLSQP use different algorithms; agreement of the likelihood and
solution is the relevant check.
